# Changelog

## 1.1.0 — Learn through connections

- Strict TypeScript, explicit contracts, shared atlas rules/UI, isolated browser adapters, and focused feature folders; no client framework dependency.
- A clear `ARCHITECTURE.md`, lean agent/developer guides, reproducible source ingestion, formatting, and CI checks.
- 11 shared learning axes and six configurable games; actual ordered A–Z journeys, neighbors, languages, clock proximity, and memory postcards.
- Larger typography and prominent, consistent multi-region banners. Türkiye, Russia, Egypt, Kazakhstan, Indonesia, and convention-dependent cases are never reduced to contradictory quiz answers.
- Source-attributed flag explanations, language/faith context, border connections, and civil time-zone information for all 197 entries.
- 627 local narration clips, including flag stories; original passport progress retained.
- Reviewed visual features replace prose regexes; correct band counts and Ashoka Chakra wording; unsupported clocks, near-identical flags, uncertain borders, and undersized pools cannot produce unfair questions.
- Retired the monolithic app, duplicate data globals, old generation scripts, and 56 obsolete recordings. Generated JS/CSS and source caches are not committed.

## 1.0.0 — Initial public release

- Little Atlas brand and responsive, child-friendly interface.
- All 195 UN member/observer states plus clearly labeled Taiwan and Kosovo entries.
- Flag memory clues, real map locations, gentle two-choice practice, and local passport progress.
- 287 local Olivia / MAI-Voice-2 audio clips with replay and stop controls.
- Keyboard support, reduced-motion layouts, and intentional focus styling.
- Allowlisted static Pages build, private-file exclusion, custom 404, and security headers.
- Regression coverage for all 197 learning journeys, game modes, audio, persistence, and responsive layouts.
